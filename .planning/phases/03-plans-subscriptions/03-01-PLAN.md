   - GET /api/customers/:id: Protected: authenticateToken + requireCustomerOwnership('id'). Returns customer details, full subscription history, and invoices.

   - GET /api/subscriptions: Protected: authenticateToken. If ADMIN: returns all subscriptions. If CUSTOMER: returns only subscriptions belonging to req.user.customerId.
   - POST /api/subscriptions: Protected: authenticateToken + requireRole('ADMIN').

     - Verifies plan is active (isActive === true); rejects with HTTP 400 if inactive.
     - Computes currentPeriodStart and currentPeriodEnd via calculateNextRenewalDate.
     - Creates Subscription with status: 'ACTIVE'. Returns HTTP 201.
   - PATCH /api/subscriptions/:id/cancel: Protected: authenticateToken.
     - If CUSTOMER: verifies customer ownership.
     - Supports query/body { immediate: boolean }:
       - immediate === true: status becomes 'CANCELLED'.
       - immediate === false: cancelAtPeriodEnd becomes true, status remains 'ACTIVE' until periodEnd.
Mount customersRouter at /api/customers and subscriptionsRouter at /api/subscriptions in backend/src/app.ts.</action>
