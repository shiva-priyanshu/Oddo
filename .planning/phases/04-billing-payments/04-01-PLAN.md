<task type="tracer">
  <name>Task 1: Invoice Financial Calculation & Numbering Engine</name>
  <files>backend/src/lib/invoice-calc.ts</files>
  <action>Implement backend/src/lib/invoice-calc.ts providing financial arithmetic and formatting utilities:
1. calculateInvoiceFinancials(items: Array<{ unitPrice: number, quantity: number }>, discountAmount: number = 0, taxRate: number = 10):
   - Computes subtotal = sum(unitPrice * quantity).
   - Computes taxableAmount = max(0, subtotal - discountAmount).
   - Computes taxAmount = round(taxableAmount * (taxRate / 100), 2).
   - Computes total = round(taxableAmount + taxAmount, 2).
   - Returns { subtotal, discountAmount, taxRate, taxAmount, total }.
2. generateNextInvoiceNumber(): Promise<string>
   - Queries highest sequential invoice number for current year from database (e.g. INV-2026-0003) and increments sequentially.
3. computeLiveInvoiceStatus(invoice: { status: string, total: number, dueDate: Date, payments: Array<{ amount: number }> }): string
   - Computes paidAmount = sum of payment amounts.
   - If paidAmount >= invoice.total, returns 'PAID'.
   - If paidAmount < invoice.total and Date.now() > invoice.dueDate.getTime(), returns 'OVERDUE'.
   - Otherwise returns invoice.status.</action>

  </verify>
  <done>Financial calculation helper calculates subtotal, tax, and total accurately with 2-decimal precision.</done>
