<task type="tracer">
  <name>Task 1: Timing-Safe Cryptographic JWT Service</name>
  <files>backend/src/lib/jwt.ts</files>
  <action>Implement backend/src/lib/jwt.ts using Node.js built-in crypto module:
1. Define TokenPayload interface:
   - userId: string
   - email: string
   - role: 'ADMIN' | 'CUSTOMER'
   - customerId?: string
   - iat: number
   - exp: number
2. signToken(payload: Omit<TokenPayload, 'iat' | 'exp'>, expiresInSeconds = 86400): string
   - Creates header {"alg": "HS256", "typ": "JWT"}.
   - Adds iat (current unix seconds) and exp (iat + expiresInSeconds).
   - Base64url encodes header and payload.
   - Computes HMAC-SHA256 signature using process.env.JWT_SECRET (fallback: 'subscriptiq-dev-jwt-secret-replace-in-production').
   - Returns `${header}.${payload}.${signature}`.
3. verifyToken(token: string): TokenPayload
   - Splits token into 3 parts; throws 'MALFORMED_TOKEN' if count !== 3.
   - Recomputes expected HMAC signature.
   - Uses crypto.timingSafeEqual to compare signatures, preventing timing side-channel attacks; throws 'INVALID_SIGNATURE' if mismatch.
   - Decodes payload; validates presence of userId, email, role.
   - Compares exp with Math.floor(Date.now() / 1000); throws 'TOKEN_EXPIRED' if past expiration.</action>
  <verify>
    <automated>node -e "const { signToken, verifyToken } = require('./backend/dist/lib/jwt'); const t = signToken({ userId: 'u1', email: 'test@example.com', role: 'ADMIN' }); const v = verifyToken(t); if (v.userId !== 'u1' || v.role !== 'ADMIN') process.exit(1);"</automated>
  </verify>
  <done>JWT service signs and verifies tokens timing-safely, rejects expired or tampered signatures, and compiles without errors.</done>
</task>

<task type="auto">
  <name>Task 2: Authentication, RBAC & Customer Data Isolation Middlewares</name>
  <files>backend/src/middleware/auth.ts</files>
  <action>Implement backend/src/middleware/auth.ts:
1. Extend Express Request interface to include user?: TokenPayload.
2. authenticateToken:
   - Extract Authorization header ('Bearer <token>').
   - If missing, return HTTP 401 { error: 'Authentication token required', statusCode: 401 }.
   - Call verifyToken(token). If error, return HTTP 401 { error: 'Invalid or expired token', statusCode: 401 }.
   - Set req.user = payload and proceed.
3. requireRole(...allowedRoles: Array<'ADMIN' | 'CUSTOMER'>):
   - Check req.user.role.
   - If not in allowedRoles, return HTTP 403 { error: 'Access forbidden: insufficient permissions', statusCode: 403 }.
4. requireCustomerOwnership(paramName = 'customerId'):
   - If req.user.role === 'ADMIN', allow immediately.
   - If req.user.role === 'CUSTOMER': compare req.user.customerId with req.params[paramName].
   - If mismatch or undefined, return HTTP 403 { error: 'Access forbidden: cannot access another customer data', statusCode: 403 }.</action>
  <verify>
    <automated>npm --prefix backend run build</automated>
  </verify>
  <done>Auth and RBAC middlewares enforce token validity, role boundaries, and cross-customer isolation.</done>
